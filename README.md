> **Discover. Compare. Shop Smarter.**

Showcasely is a modern AI-powered electronics showcase platform that helps users discover, compare, and explore the latest gadgets with verified specifications, interactive product views, and intelligent shopping assistance.

- 🔍 Smart product search
- 🤖 AI Shopping Assistant
- 📱 Premium electronics catalog

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/showcasely.git
```

Go to project directory

```bash
cd showcasely
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```
